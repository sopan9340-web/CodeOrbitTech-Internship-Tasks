# Password Strength Checker

A command-line Python program that checks basic password characteristics and provides improvement tips.

## Run
```bash
python password_checker.py
```

## Checks
- Minimum length of 8 characters, with 12+ recommended
- Uppercase and lowercase letters
- Numbers
- Special characters

## Privacy
The password is processed locally and is not written to a file or sent over a network. For a demo, use a made-up sample password.

## Limitation
This is an educational checker, not a full password-security audit. It does not check breached-password databases or detect every predictable pattern.
