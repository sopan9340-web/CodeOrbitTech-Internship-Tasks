# CodeOrbitTech Internship Tasks

This repository contains three beginner-friendly Python cybersecurity projects:
1. Password Strength Checker
2. Caesar Cipher Encryption Tool
3. Phishing Email Identifier

## Technologies Used
- Python 3
- Python standard library only (no external packages)

## Project 1: Password Strength Checker
### Features
- Checks password length
- Checks uppercase and lowercase letters
- Checks numbers and special characters
- Gives actionable suggestions to improve weak passwords
- Does not store or transmit passwords

### Run
```bash
python password_strength_checker/password_checker.py
```

## Project 2: Caesar Cipher Encryption Tool
### Features
- Encrypts and decrypts text using a user-selected shift/key
- Preserves spaces, punctuation, and letter case
- Supports negative and large shift values

### Run
```bash
python caesar_cipher/caesar_cipher.py
```

> Note: Caesar cipher is a learning exercise, not secure encryption for protecting sensitive information.

## Project 3: Phishing Email Identifier
Includes a checklist, five fictional sample emails, classifications, and a short report.
